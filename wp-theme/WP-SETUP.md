# WordPress: установка темы «Влата» и подготовка к хостингу

Кастомная тема в папке `wp-theme/vlata/`. Дизайн и механика статического сайта сохранены 1:1 (те же `style.css`, `pages-style.css`, шапка/футер/меню/телефонные кнопки). WooCommerce работает в режиме каталога: без корзины, оплаты и цен «В корзину» — только фото, описания и кнопка «Уточнить по телефону».

---

## 1. Что даёт WP-админка клиенту (главная цель переноса)

| Задача клиента | Где в админке |
|---|---|
| Добавить фото в категорию (гробы, венки, памятники…) | **Товары → Добавить товар** → выбрать категорию → «Загрузить изображение товара» (главное фото) + «Галерея товаров» (остальные фото) |
| Новая категория фотографий | **Товары → Категории** (родители: «Похоронные услуги» / «Памятники») |
| Изменить тексты на странице категории | **Товары → Категории → Изменить → Описание** |
| Изменить пакеты и цены на главной | **Пакеты услуг** (цена «от», состав — строка = пункт; `**жирный**` — выделение, строка с `—` — подпункт) |
| Изменить телефоны, email, адрес, режим работы | **Внешний вид → Настроить → Контакты — Влата / Данила Мастер** |
| Тексты «О компании» и галереи | **Страницы → О компании** (обычный редактор) |

Фото появляются автоматически: на странице категории, в «Наши работы» и на странице товара. Порядок фото = порядок в галерее товара; порядок товаров = поле «Порядок».

Формула для «паков контента»: один товар = один набор фото. Например «Венок №12» → 3 фото → все 3 появятся в категории «Венки и корзины».

## 2. Установка (порядок важен)

1. **Хостинг**: PHP 8.1+ (лучше 8.2/8.3), MySQL 8 / MariaDB 10.4+, SSL (Let's Encrypt), домен. Подойдут Timeweb, Beget, REG.RU, SpryHosting.
2. Установить WordPress (у большинства хостингов — в 1 клик). При установке: логин админа **не** `admin`, пароль из менеджера паролей, чекбокс «запретить индексацию поисковиками» НЕ ставить (если ставится — снять в Настройки → Чтение после запуска).
3. Установить плагин **WooCommerce** и пройти мастер настройки: страна Россия, валюта рубль, **не** создавать страницы Магазин/Корзина/Оформление («Skip setup» в шаге создания страниц — тема работает без них; если мастер создал — их можно удалить, корзина редиректит на главную).
4. Загрузить тему: `wp-theme/vlata` заархивировать в `vlata.zip` (архивировать **папку целиком**) → Внешний вид → Темы → Добавить → Загрузить → Активировать. Если хостинг режет большие файлы — загрузить папку по FTP в `wp-content/themes/`.
5. **Инструменты → Импорт каталога Влата**: указать адрес старого статического сайта (Vercel, например `https://xxxx.vercel.app`) → «Запустить импорт». Создаст: 7 страниц, 12 категорий WooCommerce, 10 товаров-фотогалерей (93 фото скачаются со старого сайта в Медиафайлы), 3 пакета услуг.
6. Настройки → Постоянные ссылки → «Название записи» → Сохранить (дважды).
7. Настройки → Чтение → «Статическая страница» → Главная = любая (front-page.php возьмёт главную автоматически, но выбрать страницу стоит для корректной пагинации/SEO).
8. WooCommerce → Настройки → Товары → убрать галочки рейтингов/отзывов (не нужны для каталога).
9. Проверить сайт: меню обоих брендов, страницы категорий, кнопки «Уточнить по телефону», мобильное меню.

**Старые URL** (`/pages/coffins.html`, `/danila-master/granite.html` и т.п.) автоматически редиректят 301 на новые страницы — SEO не пострадает.

## 3. Плагины

### Обязательные
| Плагин | Зачем |
|---|---|
| **WooCommerce** | Каталог товаров/категорий, админка для фото |
| **Rank Math SEO** (или Yoast) | title/description, sitemap.xml, Open Graph, редиректы |
| **Wordfence Security** | Файрвол (WAF), сканер малвари, 2FA, лимит попыток входа — всё в одном |
| **UpdraftPlus** | Автобэкап сайта + БД (в Яндекс.Диск / Google Drive), расписание раз в день |
| **WPS Hide Login** | Скрытие `/wp-admin` и `/wp-login.php` на секретный URL |

### Рекомендуемые
| Плагин | Зачем |
|---|---|
| **LiteSpeed Cache** (или WP Super Cache) | Кэш + ускорение; LiteSpeed — если хостинг на LiteSpeed (Beget, Timeweb) |
| **Converter for Media** | Авконвертация фото в WebP — сайт быстрее, фото в категории весят меньше |
| **Editoria12 / Clearfy** (необязательно) | Мелкая чистка WordPress |

Больше плагинов = больше surface атаки. Не ставить «сборники» и бандлы из 50 функций.

## 4. Безопасность перед хостингом (чек-лист)

### wp-config.php (открыть файл и добавить/проверить)
```php
define('DISALLOW_FILE_EDIT', true);      // запрет правки файлов темы/плагинов из админки
define('DISALLOW_FILE_MODS', true);      // (осторожно: отключит и обновления плагинов из админки — можно не ставить, если нужен автоапдейт)
define('WP_AUTO_UPDATE_CORE', 'minor');  // автопатчи безопасности ядра
define('FORCE_SSL_ADMIN', true);         // админка только по HTTPS
```
- Ключи SALTS заменить на свежие: https://api.wordpress.org/secret-key/1.1/salt/ (инвалидирует все сессии).
- Префикс таблиц не стандартный `wp_` (задаётся при установке; если забыли — оставить как есть, менять опасно).
- Файл `wp-config.php` — права **600/640**.

### Права файлов (по FTP/SSH)
```
папки 755, файлы 644
wp-config.php 600
.htaccess 644 (после правок)
запрет выполнения php в wp-content/uploads (см. .htaccess ниже)
```

### .htaccess в папке wp-content/uploads (запрет исполнения скриптов — главная защита от заливки шелла)
```apache
<FilesMatch "\.(php|php5|phtml|pl|py|cgi|sh)$">
  Require all denied
</FilesMatch>
```

### Корневой .htaccess — заголовки безопасности и запрет листинга
```apache
Options -Indexes
<IfModule mod_headers.c>
  Header always set X-Content-Type-Options "nosniff"
  Header always set X-Frame-Options "SAMEORIGIN"
  Header always set Referrer-Policy "strict-origin-when-cross-origin"
  Header always set Permissions-Policy "camera=(), microphone=(), geolocation=()"
</IfModule>
# Отключить XML-RPC (частая точка брутфорса)
<Files xmlrpc.php>
  Require all denied
</Files>
```

### Админка и учётные записи
- Один админ + при необходимости «Редактор» для клиента (менеджер магазина — роль Shop Manager, если сам управляет товарами).
- **Wordfence → Login Security**: включить 2FA (Google Authenticator), лимит попыток (3), блок по IP на 4 часа, скрыть логин.
- WPS Hide Login: сменить `/wp-admin` → например `/vlata-admin-2026` (никому не публиковать этот URL).
- Пароли: только из менеджера паролей, длина 20+.

### Обновления и мониторинг
- Обновлять WP/плагины **раз в неделю** (уведомления на email в Wordfence).
- Никогда не ставить null/warez-темы и плагины «с форумов».
- Проверять в Wordfence Scan раз в 2 недели.
- Удалять неиспользуемые плагины и темы (не «отключить», а «удалить»).

### Бэкапы (UpdraftPlus)
- Расписание: файлы раз/нед, БД раз/день, хранить 14 копий, выгрузка в облако (Яндекс.Диск/Google Drive).
- Один раз сделать **восстановление из бэкапа** на поддомене — проверить, что бэкап рабочий.

### Хостинг-уровень
- PHP 8.2+, `display_errors = Off`, `allow_url_fopen` можно выключить после импорта (импортеру нужен на время скачивания фото).
- Включить ограничение FTP/SSH по IP, если интернет-провайдер даёт статический IP.
- Cloudflare перед доменом (бесплатный тариф) — скроет IP сервера, базовая защита от DDoS и ботов.

## 5. После запуска

- Rank Math: заполнить title/description главных страниц, отправить sitemap (`/sitemap_index.xml`) в Яндекс.Вебмастер и Google Search Console.
- Проверить в PageSpeed Insights; включить кэш и WebP.
- В `robots.txt` (Rank Math) добавить `Disallow: /wp-admin/`, `Disallow: /*?s=` и скрытый URL логина.
- Домен старого сайта (Vercel) держать с 301-редиректом на новый домен минимум 3–6 месяцев, пока страницы не переиндексируются.

## 6. Структура темы (для разработчика)

```
vlata/
├── style.css                  # тема + все стили сайта (путь hero-bg исправлен)
├── functions.php              # подключение, enqueue, каталог Woo без корзины, 301-редиректы старых URL
├── header.php / footer.php    # двухбрендовая шапка/футер (порт js/chrome.js на PHP)
├── front-page.php             # главная Влата (пакеты из CPT)
├── page.php                   # страницы (about/danila-about рендерят контент из редактора)
├── page-*.php                 # шаблоны: контакты, работы, Данила Мастер (главная/контакты/работы)
├── woocommerce/
│   ├── taxonomy-product_cat.php  # категория: карточки дочерних категорий ИЛИ текст+фото-грид
│   ├── archive-product.php       # /shop/ → два бренда
│   └── single-product.php        # товар: фото-грид + «Уточнить по телефону»
├── inc/
│   ├── config.php             # телефоны/адреса + Customizer (Внешний вид → Настроить)
│   ├── brand.php              # определение бренда (Влата/Данила) + JSON-LD
│   ├── packages.php           # CPT «Пакеты услуг» + fallback из catalog.json
│   └── importer.php           # Инструменты → Импорт каталога (страницы/категории/товары/фото)
├── assets/{css,js,img}/       # pages-style.css, theme.js, hero-bg.jpg
└── data/catalog.json          # машиночитаемый каталог: 12 категорий, 93 фото, пакеты
```

Фото хранятся в Медиафайлах WordPress; тема берёт их из товаров (`_thumbnail_id` + `_product_image_gallery`).

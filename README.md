# LeRn

Сайт ритуальной службы «Влата» и «Данила Мастер».

Восстановленная версия сайта ритуальной службы по сохранившимся скриншотам.

## Структура проекта

```
/
├── index.html          # Главная страница
├── style.css           # Стили сайта
├── script.js           # JavaScript функциональность
├── images/            # Папка для изображений
├── README.md          # Этот файл
└── docs/              # Документация (создается отдельно)
```

## Особенности реализации

### ✅ Реализовано

- **Точная верстка** по скриншотам
- **Адаптивный дизайн** для всех устройств
- **Анимированная навигация** с выпадающими меню
- **Hero-секция** с слайдером
- **Карточки услуг** с ценами
- **Интерактивные элементы** и hover-эффекты
- **Плавные анимации** и переходы

### 🎨 Дизайн-система

**Цвета:**
- Основной фон: `#1a1a1a`
- Золотистый акцент: `#D4AF37`
- Синие кнопки: `#4A90E2`
- Белый текст: `#ffffff`

**Типографика:**
- Основной шрифт: Segoe UI, Tahoma, Geneva, Verdana
- Заголовки: 48px/36px/28px (desktop/tablet/mobile)
- Основной текст: 16px/14px

### 📱 Адаптивность

- **Desktop**: > 1024px
- **Tablet**: 768px - 1024px  
- **Mobile**: < 768px
- **Small Mobile**: < 480px

## Запуск проекта

### Простой запуск
Откройте файл `index.html` в браузере

### Локальный сервер (рекомендуется)
```bash
# Python 3
python -m http.server 8000

# Python 2
python -m SimpleHTTPServer 8000

# Node.js
npx http-server

# PHP
php -S localhost:8000
```

Откройте: http://localhost:8000

## Секции сайта

### 1. Header & Navigation
- Фиксированное меню сверху
- Выпадающие подменю для "Похоронные услуги" и "Памятники"
- Адаптивное мобильное меню

### 2. Hero Section
- Полноэкранная секция с фоновым изображением
- Анимированный слайдер с 3 слайдами
- CTA-кнопка "Заказать" с иконкой телефона
- Список преимуществ с золотистыми галочками

### 3. Services Section  
- Карточки пакетов услуг
- Детальные списки включенных услуг
- Цены и кнопки заказа
- Hover-эффекты и анимации

## Интеграция изображений

### Фоновые изображения
Поместите подходящие изображения в папку `images/`:
- `hero-bg.jpg` - фон для hero секции (рекомендуемый размер: 1920x1080px)
- `service-bg.jpg` - фон для секции услуг

### Галерея работ  
Используйте изображения из папки "Наши работы":
```
images/gallery/
├── 1.jpg
├── 2.jpg
├── ...
└── 26.jpg
```
